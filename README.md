## 📝 О проекте

**MSHP Answers** - это веб-приложение, созданное по мотивам популярных платформ вопросов и ответов (таких как Stack Overflow, "Ответы Mail.ru" и др.). Пользователи могут задавать вопросы, оставлять ответы, голосовать за контент и управлять своим профилем.

### Основные возможности

-  **Аутентификация пользователей** - регистрация, вход, выход
-  **Управление вопросами** - создание, просмотр, фильтрация по тегам
-  **Система ответов** - возможность отвечать на вопросы других пользователей
-  **Голосование** - система лайков/дизлайков для вопросов и ответов
-  **Теги** - категоризация вопросов с помощью тегов
-  **Поиск** - поиск вопросов по заголовку и содержанию
-  **Профили пользователей** - аватары, биография, просмотр активности
-  **Личный кабинет** - просмотр своих вопросов и ответов

- **Django 5.x** - основной фреймворк
- **SQLite** - база данных (по умолчанию)
- **Django ORM** - работа с базой данных

### Frontend
- **HTML5/CSS3** - разметка и стили
- **JavaScript (Vanilla)** - динамические элементы
- **SVG** - иконки для интерфейса

### Инструменты
- **Git** - контроль версий

## 📋 Функциональные требования

### Пользователи
- Регистрация нового пользователя
- Авторизация и аутентификация
- Редактирование профиля (аватар, биография)

### Вопросы
- Создание вопроса с заголовком, текстом и тегами
- Просмотр списка вопросов на главной странице
- Фильтрация вопросов по тегам
- Поиск по заголовку и содержанию
- Просмотр отдельного вопроса с ответами

### Ответы
- Добавление ответов на вопросы
- Голосование за ответы
- Отображение рейтинга ответов

### Голосование
- Лайки и дизлайки для вопросов
- Лайки и дизлайки для ответов
- Изменение и отмена голоса

# Список команд для работы с проектом
## В первую очередь скачайте зависимости! Так же нужно установить виртуальную среду (venv), если она не установлена.

``pip install -r requirements.txt`` - скачивание зависимостей проекта

``python3 manage.py runserver`` - запуск сервера, а следовательно и сайта

``python3 manage.py test`` - запуск тестирования проекта при помощи Django Test Framework

``python3 manage.py createsuperuser`` - создать администратора в базу данных.

``python3 manage.py migrate`` - применить файлы миграций на базу данных

``python3 manage.py makemigrations`` - создать файлы миграций для базы данных из models.py
